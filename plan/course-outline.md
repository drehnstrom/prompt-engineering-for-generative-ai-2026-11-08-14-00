# Course Title: Prompt Engineering for Generative AI (1 hour)

## Course Description

Generative AI models can produce remarkable text, code, and insights, but getting reliable, high-quality results requires carefully crafted instructions. Without clear prompting techniques, users often struggle with vague outputs, hallucinations, and inconsistent formatting.

This course teaches practical prompt engineering techniques using Gemini. Students explore core prompting principles, structured input patterns, and iterative refinement strategies to effectively build prompts and secure quality results.

## Learning Objectives

- Effectively build prompts to get quality results
- Understand core prompt engineering principles and how large language models interpret instructions
- Apply structured prompt patterns and iterative refinement techniques using Gemini

## Who Should Attend

Beginners with a little Generative AI exposure who want to learn how to write effective prompts and get reliable, high-quality results from AI models.

## Prerequisites

- A little Generative AI exposure

## Hands-On Activities

- Lab: Prompt Engineering with Gemini
